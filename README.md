# backbone-bitassets

Drop-in replacement client for **BitAssets on eCash (slot 4)**: consensus-, P2P-, mainchain-
and RPC-compatible with the octobocto fork of plain-bitassets v0.17.1 (16f2f69), which is what
betanet runs. C++20 on the shared engine `backbone-core` (submodule `core`, branch `main`).

* `doc/bitassets.md`: status, drop-in surface, reproduced quirks, kept fixes, proposals, open questions.
* `doc/differential-tests.md`: the regtest differential harness against their binary and the oracle.
* `core/doc/DESIGN.md`: the engine.

Inspired by BitAssets by LayerTwo Labs.

## Layout

```
core/               git submodule ../backbone-core (engine, generic sidechain Node<C>, PegState, side tips)
chains/bitassets/   libbitassets_core (types, merkle, state machine incl. AMM and Dutch auctions,
                    JSON, betanet fixture); libbitassets_node (wallet, app/RPC);
                    binaries bitassets, bitassets-cli, bitassets-fetch-blocks
tests/              known answers (tests/data/betanet = public betanet data), oracle cases
                    generated by their own code (tests/data/oracle), node hardening tests
tools/oracle/       Rust oracle linking their lib crate (ext/plain-bitassets-octobocto, pinned)
tools/diffba.py     local regtest differential harness (their node and ours on one mainchain)
```

## Build (Linux)

As backbone-bitnames: build `core/depends`, then

```
cmake -S . -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build -j4
build/tests/bt_tests
```

## Run on betanet

```
bitassets --headless --bt-mainchain-grpc-url https://enforcer.beta.ecash.ninja   # public enforcer (TLS)
bitassets --headless --mainchain-grpc-host 127.0.0.1 --mainchain-grpc-port 50051
bitassets-cli getblockcount            # default --rpc-host 127.0.0.1 --rpc-port 6004
```

Defaults as theirs: P2P 0.0.0.0:4004 (magic cc 06 58 04), RPC 127.0.0.1:6004, ZMQ 127.0.0.1:28004.
